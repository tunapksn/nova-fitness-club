# 🏋️ NOVA FITNESS CLUB

### WordPress Tabanlı Spor Salonu Web Sitesi

**NOVA FITNESS CLUB**, spor salonu hizmetlerini dijital ortamda tanıtmak, üyelik seçeneklerini sunmak ve kullanıcıların online rezervasyon yapabilmesini sağlamak amacıyla geliştirilmiş bir web sitesi projesidir.

Proje, WordPress içerik yönetim sistemi kullanılarak hazırlanmıştır. Modern, siyah-beyaz tasarımı ve kullanıcı dostu arayüzüyle ziyaretçilerin ihtiyaç duydukları bilgilere kolayca ulaşması hedeflenmiştir.

---

## 🎯 Projenin Amacı

Spor salonuna ait hizmetlerin tek bir platform üzerinden sunulması, antrenman programlarının tanıtılması ve üyelik ile rezervasyon işlemlerinin kolaylaştırılması amaçlanmıştır.

## ✨ Web Sitesinin Özellikleri

- 🏠 **Ana Sayfa:** Spor salonu tanıtımı ve genel bilgiler
- 💪 **Bireysel Antrenman:** Kişiye özel antrenman seçenekleri
- 👥 **Grup Dersleri:** Grup antrenmanları ve ders bilgileri
- 🏋️ **Personal Training (PT):** PT paketleri, seans bilgileri ve ücretlendirme
- 👨‍🏫 **Antrenörlerimiz:** Antrenör fotoğrafları ve tanıtım bilgileri
- 📅 **Online Rezervasyon:** Randevu ve rezervasyon işlemleri
- 💳 **Üyelik Paketleri:** Üyelik seçenekleri ve paket bilgileri
- 🏢 **Spor Salonu:** Salonun fiziksel alanları ve sunduğu imkânlar
- 📝 **İletişim Formları:** Kullanıcı taleplerinin alınması ve veritabanına kaydedilmesi
- ♿ **Erişilebilirlik:** Kullanıcıların siteye erişimini kolaylaştıran özellikler
- 📱 **Responsive Tasarım:** Mobil, tablet ve bilgisayar ekranlarına uyumlu yapı

## 🛠️ Kullanılan Teknolojiler

| Teknoloji | Kullanım Amacı |
|---|---|
| WordPress | İçerik yönetim sistemi |
| PHP | Sunucu tarafı altyapısı |
| MySQL / MariaDB | Veritabanı |
| XAMPP | Yerel geliştirme ortamı |
| Astra | WordPress teması |
| Amelia Booking | Online rezervasyon sistemi |
| WPForms Lite | Form oluşturma |
| Database for WPForms | Form kayıtlarının saklanması |
| WP Accessibility | Erişilebilirlik özellikleri |
| GitHub | Proje tanıtımı ve sürüm takibi |

## 🎨 Tasarım

Web sitesinde siyah-beyaz renk konsepti kullanılmıştır.

Tasarımda modern görünüm, kolay gezinme, okunabilir içerikler ve spor salonu kimliğine uygun görsel bütünlük ön planda tutulmuştur.

## 📂 Proje Teslim Dosyaları

Projenin teslim paketinde aşağıdaki dosyalar bulunmaktadır:

- `sporsitesi/` — WordPress proje klasörü
- `sporsitesi (2).sql` — Veritabanı yedeği
- `novafitnessclub.WordPress.2026-11-23.xml` — WordPress içerik dışa aktarımı
- `KURULUM.txt` — Kurulum yönergesi

**Not:** Web sitesi XAMPP üzerinde yerel ortamda geliştirilmiştir. Çalışan projenin kurulumu için WordPress dosyaları ve veritabanı yedeği gereklidir. Bu GitHub deposu projenin tanıtımı amacıyla kullanılmaktadır.
